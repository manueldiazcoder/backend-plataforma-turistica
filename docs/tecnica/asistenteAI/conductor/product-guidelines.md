# Guía de Producto: Pautas

## Tono y Estilo de Comunicación

El tono de la marca debe ser **cercano, amigable y con un espíritu aventurero**. El objetivo es motivar a los usuarios a explorar tanto la plataforma como el municipio sobre el que investigan. La comunicación debe ser cálida, accesible y conversacional, despertando la curiosidad y el deseo de aventura.

## Identidad Visual

La estética visual debe ser **vibrante y dinámica**, pero sin ser exagerada. Se utilizarán colores vivos y elementos gráficos atractivos para crear una interfaz enérgica que evoque emoción y aventura. La paleta de colores se inspirará en tonos probados en sitios web de temática similar, pero será única para diferenciar y destacar la plataforma.

## Pautas de Desarrollo

### Flujo de Trabajo con Git

Se utilizará un flujo de trabajo basado en **GitFlow simplificado** para mantener el código organizado y escalable. Las ramas principales son `main` y `develop`, con ramas de soporte para `feature`, `bugfix`, `release`, y `hotfix`.

### Convención de Commits

Se seguirá la convención de **Conventional Commits** para mantener un historial de commits claro y legible. Los prefijos a utilizar son: `feat`, `fix`, `chore`, `docs`, `refactor`, y `test`.
