# Guía de Producto: Backend Calima Explorer

## Concepto Inicial

Este repositorio del backend para la Plataforma Turística tiene como objetivo centralizar y organizar la oferta turística y comercial de los municipios, mejorando la visibilidad de los negocios locales y proporcionando a los visitantes información fiable. Está diseñado con los principios de Arquitectura Limpia y SOLID para asegurar una solución modular, mantenible y escalable.

## Características Clave (Inferidas del README)

*   **Autenticación de Usuarios:** Registro e inicio de sesión con JWT.
*   **Gestión de Negocios Locales:** Funcionalidad para la gestión de negocios locales (por ejemplo, hoteles, restaurantes, guías turísticos).
*   **Información de Lugares Turísticos:** Gestión de la información de los lugares turísticos.
*   **Mapa Interactivo:** API GeoJSON para la visualización de un mapa interactivo.
*   **Documentación de la API:** Swagger/OpenAPI 3.0 para la documentación completa de la API.

## Principios de Arquitectura (Inferidos del README)

*   **Arquitectura Limpia:** Separación clara entre dominio, aplicación y adaptadores.
*   **Arquitectura Estridente (Screaming Architecture):** Código organizado por funcionalidades, no por capas técnicas.
*   **Diseño Guiado por el Dominio (DDD):** Enfoque en la lógica del dominio turístico.
*   **API Basada en Contrato (Contract-first API):** Documentación utilizando OpenAPI / Swagger.
